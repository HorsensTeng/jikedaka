## 概述

这是一个基于 React + TypeScript + Vite 的单页前端演示项目，主题为“南京玄武湖下一站打卡推荐”。它通过组件内状态模拟页面流转，结合短视频弹层、手势切换和手机壳 UI，构建出接近抖音信息流体验的旅游推荐原型。
